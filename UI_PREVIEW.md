## 🎯 互動功能展示

### 1. 搜尋輸入
- **描述**: 使用者輸入商品關鍵字
- **驗證**: 不能為空
- **支援**: Enter 鍵快速搜尋

### 2. 平台選擇
- **描述**: 可選擇一個或多個購物平台
- **驗證**: 至少選擇一個平台
- **狀態**: 預設全選

### 3. 商品卡片懸停效果
```
正常狀態:
┌────────────────────┐
│  商品資訊            │
└────────────────────┘

懸停狀態:
┌────────────────────┐
│  商品資訊            │ ← 卡片上浮
│                    │ ← 顯示陰影
└────────────────────┘
```

### 4. 評分顏色編碼
- **80+ 分**: 🟢 綠色（優秀）
- **60-79 分**: 🟠 橙色（良好）
- **< 60 分**: 🔴 紅色（一般）

### 5. 按鈕互動
```
前往購買按鈕:
┌──────────────┐
│ 🛒 前往購買   │ ← 點擊後顯示購買資訊
└──────────────┘

查看詳情按鈕:
┌──────────────┐
│ 📝 查看詳情   │ ← 點擊後顯示完整資訊
└──────────────┘
```

## 🎨 配色方案

### 主色調
- **主要色**: 紫藍漸層 (#667eea → #764ba2)
- **背景**: 漸層背景
- **卡片**: 白色 (#ffffff)

### 平台標籤顏色
- **蝦皮**: 🔴 橘紅色 (#ee4d2d)
- **PChome**: 🔴 紅色 (#e4002b)
- **Momo**: 🟠 橙色 (#ff6600)

### 評分顏色
- **高分 (80+)**: 🟢 綠色 (#4caf50)
- **中分 (60-79)**: 🟠 橙色 (#ff9800)
- **低分 (<60)**: 🔴 紅色 (#f44336)

## 🔄 使用流程動畫

```
1. 使用者開啟網站
   ↓
2. 輸入搜尋關鍵字 (例: "iPhone 15")
   ↓
3. 選擇要搜尋的平台 (預設全選)
   ↓
4. 點擊搜尋按鈕或按 Enter
   ↓
5. 顯示載入動畫 (旋轉圖示)
   ↓
6. 後台處理:
   ├─ 收集商品資料
   ├─ AI 分析評論
   ├─ 計算評分
   └─ 排序結果
   ↓
7. 顯示 Top 5 商品卡片
   ↓
8. 使用者可以:
   ├─ 查看 AI 分析結果
   ├─ 點擊前往購買
   └─ 查看詳細資訊
```

## 🌟 特色功能展示

### AI 評語範例
- ✅ "價格非常合理，評價可信度高"
- ✅ "價格合理，評價可信度高"
- ⚠️ "價格合理，評價可信度中等"
- ⚠️ "價格偏高，評價較少"

### 即時反應
- 輸入驗證即時回饋
- 搜尋按鈕禁用防止重複點擊
- 載入動畫流暢
- 錯誤訊息 5 秒自動消失

### 無障礙設計
- 語義化 HTML
- 適當的對比度
- 鍵盤導航支援
- 螢幕閱讀器友善
